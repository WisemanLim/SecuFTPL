# impl/44th — 레코드 내용 div 팝업(모달) 전환 (PRD §7.15, 2026-08-14)

인자: "세부 목록에서 상단 레코드 선택 시 최하단 이동 불편 — 레코드 내용을 선택 시
div 팝업 형태로 표시하도록 수정."

PRD 갱신(§7.15 그룹핑 UX 에 모달 항목 추가 + 변경 이력) 후 구현(step 4 준수). frontend 전용.

## 범위

- [queue/page.tsx](../../../frontend/app/queue/page.tsx) — ③ 레코드 내용 패널을
  **화면 중앙 고정 오버레이(div 모달, `position: fixed; inset: 0` + 반투명 배경)** 로 전환.
  - 모달 폭 `min(980px, 100%)`, 높이 `85vh` 내부 스크롤 — 긴 payload 도 목록 위치와 무관하게 확인.
  - 닫기: 배경 클릭 · 닫기 버튼 · **ESC 키**. 모달 내부 클릭은 전파 차단.
  - 모달 내 승인/반려/삭제 기존 동작 유지(처리 후 모달 닫힘 + 그룹/세부 갱신).
- backend 변경 없음.

## 시나리오

| # | 케이스 | 기대 결과 |
|---|---|---|
| 1 | 세부 목록 상단 행 클릭 | 스크롤 이동 없이 중앙 모달로 레코드 내용 표시 |
| 2 | 배경 클릭 / 닫기 / ESC | 모달 닫힘, 목록 위치 유지 |
| 3 | 모달 내 승인/반려/삭제 | 처리 후 모달 닫힘 + 그룹·세부 목록 갱신 |
| 4 | frontend 회귀 | tsc --noEmit clean, Vitest 7건 통과 |
| 5 | backend 회귀 | 150건 통과(변경 없음 확인) |
